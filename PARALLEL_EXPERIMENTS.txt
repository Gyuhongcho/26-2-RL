연세대 마을버스 노선 실험 | 데스크톱 실행 가이드

1. 준비
GitHub의 main 브랜치를 내려받고 VS Code에서 저장소 폴더를 연다.
최신 코드가 있다면 통합 터미널에서 git pull --ff-only 를 실행한다.
기본 데이터는 팀 정제본의 서대문구 정류장 412곳과 로컬 OSRM이다.
아래 병렬 예제는 Windows PowerShell 기준이다.

2. 짧은 CPU 확인
python train.py --data network_role4_diagnostic.json --algo q-learning --steps 1000 --no-viewer --out runs/smoke

3. CUDA 확인 및 DQN 실행
CUDA를 지원하는 PyTorch를 설치한 뒤 아래 결과가 True인지 확인한다.
python -c "import torch; print(torch.cuda.is_available())"

동일한 전이 예산으로 시드 42, 43, 44를 차례로 실행한다.
GPU가 한 장이면 DQN 실행을 하나씩 배정한다.

foreach ($seed in 42,43,44) {
    python train.py --algo dqn --device cuda --steps 20000 --start-seed 42 --seed $seed --no-viewer --out "runs/dqn-$seed"
    if ($LASTEXITCODE -ne 0) { throw "DQN 실행 실패: seed $seed" }
}

4. CPU 병렬 실험
시드별로 Q-learning과 SARSA를 서로 다른 프로세스에서 동시에 실행한다.
아래 예제는 한 번에 두 프로세스를 실행한다. CPU 여유가 있으면 별도
터미널에서 다른 시드 묶음을 실행할 수 있다.

$python = (Get-Command python -CommandType Application).Source
$repo = (Get-Location).Path
foreach ($seed in 42,43,44) {
    $jobs = foreach ($algo in 'q-learning','sarsa') {
        Start-Job -ArgumentList $python,$repo,$algo,$seed -ScriptBlock {
            param($exe,$folder,$method,$s)
            Set-Location $folder
            & $exe train.py --algo $method --steps 20000 --start-seed 42 --seed $s --no-viewer --out "runs/$method-$s"
            if ($LASTEXITCODE -ne 0) { throw "실행 실패: $method seed $s" }
        }
    }
    $jobs | Wait-Job | Receive-Job
    $failed = $jobs | Where-Object State -ne 'Completed'
    $jobs | Remove-Job
    if ($failed) { throw "CPU 실험 실패: seed $seed" }
}

5. 결과 비교 및 PPT 캡처
- RL끼리는 같은 데이터, 거리 상한 10km, 보상 설정, 출발 시드,
  학습 시드 목록, 전이 예산을 사용한다. 20,000회는 초기 비교 예산이다.
- 실행별로 출력 폴더를 다르게 지정한다. 같은 폴더를 재사용하면 기록이 덮인다.
- history.jsonl은 생성 경로 전체, episode_winners.json은 에피소드별
  우승 경로, trace.json의 overall_best는 전체 학습 중 발견한 최고 경로다.
- 최고 보상은 탐험을 포함해 발견한 경로의 점수다. 학습된 정책의
  일반 성능을 나타내려면 별도 평가가 필요하다. PPT에는 시드별 최고
  점수와 경로 거리, 거점, 검증 월 하차량을 함께 기록한다.

완료한 실험을 다시 열고 「🏆 전체 최고 노선」을 눌러 캡처한다.
python train.py --replay runs/dqn-42

지도 연결에는 인터넷이 필요하며, 선은 정류장 방문 순서를 표시한다.
거리 값은 방향별 도로거리 행렬에서 계산한다.
